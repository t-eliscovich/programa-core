Códigos de cliente duplicados · qué dice Asinfo

Dos empresas distintas con el mismo código de 3 letras. Pasa porque el código son las iniciales del nombre, así que dos clientes con las mismas iniciales chocan solos (LEC = Luis Ernesto Cañamar y Lola Emperatriz Cisneros). Un código repetido duplica la plata: todo el sistema JOINea por codigo_cli, así que la comisión del vendedor se infla y el estado de cuenta muestra el saldo dos veces. Asinfo es la autoridad sobre el código de cliente — es el ERP que factura contra el RUC. Acá se cruza ficha por ficha, por los 10 primeros dígitos del RUC.

Pantalla de sólo lectura: no toca nada, ni acá ni en Asinfo. Sirve para decidir. Para borrar la fila sobrante, andá a la ficha del cliente.
